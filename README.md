# GymControl

Aplicación web para administrar las suscripciones de los socios de un gimnasio.

## ¿Para qué sirve?

Reemplaza el registro en libreta por un sistema digital que permite
registrar socios, controlar su tipo de suscripción y avisar cuando
una membresía está por vencer.

## Funcionalidades

- Registro de socios (nombre, teléfono, contacto de emergencia, foto)
- Tipos de suscripción: mensual, mensual estudiante, anual y pase de un día
- Alertas de vencimiento (2 días antes y el mismo día)
- Panel con avisos de membresías por vencer

## Tecnologías

- HTML, CSS y JavaScript
- Bootstrap 5
- Google Apps Script (backend)
- Google Sheets (base de datos)
- GitHub Pages (hosting)
